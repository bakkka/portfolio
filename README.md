# Артём — портфолио

Одностраничный сайт-портфолио: краткая информация, три проекта и интерактивная демонстрация экранов.

Проект статический — без сборки, фреймворков и зависимостей. Достаточно открыть `index.html` или запустить любой статический сервер.

## Быстрый запуск

```bash
python -m http.server 8090
```

Открыть: http://localhost:8090

Можно также использовать `npx serve`, Live Server в VS Code или просто открыть `index.html` в браузере.

## Что внутри

- **Hero** — имя, роль, короткое позиционирование и типографический блок с тремя направлениями работы.
- **Проекты** — `Testa`, `Flowdesk` и `Pulse`: описание, роль, стек, ссылки на GitHub и демонстрация.
- **Демо** — модальная галерея реальных экранов каждого проекта: лендинг, каталог/дашборд, внутренние страницы и мобильные состояния.
- **Обо мне** — био и шесть направлений работы: сайты, приложения, боты, интеграции, SEO/аналитика, UI/UX.
- **Контакт** — Telegram, e-mail, кнопка копирования, GitHub.
- Адаптив, клавиатурная навигация в галерее, `prefers-reduced-motion`, skip-link.

Lighthouse: **100 / 100 / 100** — Accessibility, Best Practices, SEO.

- **Testa** — имиджевый сайт производства плитки и кирпича ручной формовки. Каталог, форматы и цены, заявки, админка, SEO. [GitHub](https://github.com/bakkka/testa)

Скриншоты сделаны с реальных интерфейсов и лежат локально — демо работает без внешних сервисов.

## Деплой

**GitHub Pages**

1. Создать репозиторий `portfolio` и запушить содержимое этой папки в `main`.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Сайт будет доступен по адресу `https://<username>.github.io/portfolio/`. После этого обновите абсолютный `og:image`.

**Netlify / Vercel**

Подключить репозиторий или перетащить папку в Netlify Drop. Build command не нужен, publish directory — корень проекта.

## Примечания

- Данные о себе пока нейтральные — их можно уточнить позже.
